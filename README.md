# เว็บไซต์สภานักเรียนโรงเรียนร้องกวางอนุสรณ์

เว็บแอปพร้อม Backend และฐานข้อมูลในตัว เขียนด้วย **Node.js core modules ล้วน ๆ**
(ใช้ `node:sqlite` ที่มากับ Node ตั้งแต่รุ่น 22.5 ขึ้นไป) **ไม่ต้องรัน `npm install` ก็ใช้งานได้ทันที**
ข้อมูลทั้งหมดเก็บอยู่ในไฟล์ฐานข้อมูลเดียว (`data/school.db`) บนเซิร์ฟเวอร์
ทำให้คอมพิวเตอร์และมือถือที่เข้าเว็บนี้ **เห็นข้อมูลชุดเดียวกันเสมอ**

## วิธีรัน

```bash
node server.js
```

แล้วเปิดเบราว์เซอร์ไปที่ `http://localhost:3000` (หรือ `http://IP-เครื่อง:3000` จากมือถือในวงแลนเดียวกัน)

ต้องการเปลี่ยนพอร์ต: `PORT=8080 node server.js`

> ต้องใช้ **Node.js 22.5 ขึ้นไป** (ทดสอบกับ Node 22.22) เพราะใช้โมดูล `node:sqlite` ที่ยังมีสถานะทดลอง (experimental)
> — เห็น warning สีเหลืองตอนสตาร์ทได้ตามปกติ ไม่กระทบการใช้งาน

## PDF สรุปภาพรวม

ปุ่ม "ดาวน์โหลดเป็น PDF" ในหน้าสรุป (intex6.5) จะเปิดหน้าต่างพิมพ์ของเบราว์เซอร์ที่จัดหน้าเป็น
กระดาษ A4 แนวตั้งไว้ให้แล้ว เลือก "บันทึกเป็น PDF" (Save as PDF) จากตัวเลือกเครื่องพิมพ์ได้เลย

## ⚠️ ข้อควรระวังก่อนใช้งานจริง (สำคัญ)

แบบประเมินสภาพจิตใจ (intex3) เก็บข้อมูลที่ค่อนข้างอ่อนไหวของนักเรียนที่เป็นผู้เยาว์
ก่อนเปิดใช้งานจริงกับนักเรียน ควรพิจารณา:

1. **เปลี่ยนรหัสผ่านแอดมิน** จากค่าเริ่มต้น และเก็บเป็นความลับเฉพาะสภานักเรียน/ครูที่ปรึกษา
2. **เปิดใช้งาน HTTPS** หากจะให้เข้าถึงจากอินเทอร์เน็ตภายนอก (ไม่ใช่แค่วงแลนโรงเรียน) เพื่อไม่ให้ข้อมูลถูกดักฟังระหว่างทาง
3. **ให้ครูที่ปรึกษา/ครูแนะแนวรับทราบและกำกับดูแล** การเข้าถึงข้อมูลผลประเมินสภาพจิตใจ ไม่ควรให้นักเรียนทั่วไปเข้าถึงได้
4. หน้าผลประเมิน (intex3.1) ให้คำแนะนำทั่วไปเท่านั้น **ไม่ใช่เครื่องมือวินิจฉัยทางการแพทย์** — กรณีนักเรียนมีความเสี่ยงสูง ควรมีช่องทางให้ครูแนะแนว/นักจิตวิทยาโรงเรียนติดต่อกลับได้จริง ไม่ใช่แค่แสดงผลบนหน้าจอ
5. สำรองไฟล์ `data/school.db` เป็นระยะ เพื่อป้องกันข้อมูลสูญหาย

## โครงสร้างไฟล์

```
server.js          เซิร์ฟเวอร์หลัก + API
db.js              ตั้งค่าฐานข้อมูล SQLite
data/school.db     ไฟล์ฐานข้อมูล (สร้างอัตโนมัติเมื่อรันครั้งแรก)
public/            ไฟล์หน้าเว็บทั้งหมด (HTML/CSS/JS)
  css/style.css    สไตล์ชีตรวมทุกหน้า
  js/nav.js        สร้างแถบเมนูให้ทุกหน้าอัตโนมัติ
  js/api.js        ตัวช่วยเรียก API + ตรวจสอบสิทธิ์แอดมิน
  img/             ไอคอนตราโรงเรียน ตราสภา และภาพประกอบ
```
